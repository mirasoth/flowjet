# Inversion Analysis — Playbook

## Purpose

Ask how the survey/report would *guarantee* being wrong, then check whether the artifact is doing any of those things. Reveals blind spots by approaching from failure.

## When to use

- A conclusion feels airtight but you want to find what's missing
- Before Gate D on a confident draft

## Procedure

1. State the goal ("produce a defensible survey of X").
2. **Invert**: list what would guarantee failure (cherry-pick sources, over-claim grades, ignore a rival school, omit limitations).
3. Check the artifact against each inverted item.
4. For each hit, propose the corrective edit (add the missing angle, downgrade, add limitation).

## Output contract

- **Revelations** (≥1): inverted failure modes the artifact currently exhibits.
- **Proposed edits**: corrections per hit.
- **Outcome stamp**: `hardened` | `refined` | `unchanged` | `killed`.

## Anti-pattern

| Do not | Do instead |
|--------|------------|
| List generic sins ("don't be biased") | Name the specific missing angle or over-claim in this artifact |
