# Comparative Analysis Matrix — Playbook

## Purpose

Score competing schools/approaches against explicit weighted criteria so a recommendation rests on visible, defensible trade-offs instead of taste.

## When to use

- The judgment must pick between competing approaches, frameworks, or explanations
- A "winner" is asserted but the criteria are implicit

## Procedure

1. List the options and the criteria that actually matter (evidence strength, scope, generality, cost, risk).
2. Weight the criteria by how much they bear on the research question.
3. Score each option per criterion from graded evidence (no invented scores).
4. Read off the recommendation; state which criterion drives it and where it's weak.

## Output contract

- **Revelations** (≥1): the criterion that flips the ranking, and any option that wins only on an unweighted axis.
- **Proposed edits**: recommendation + rationale, sensitivity note.
- **Outcome stamp**: `hardened` | `refined` | `unchanged` | `killed`.

## Anti-pattern

| Do not | Do instead |
|--------|------------|
| Score from memory | Score only from graded, cited evidence |
